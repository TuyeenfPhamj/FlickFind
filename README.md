# FlickFind

Ứng dụng Android tra cứu phim được xây dựng bằng Kotlin và Jetpack Compose.

## Công nghệ sử dụng
- Kotlin
- Jetpack Compose
- MVVM
- Navigation Compose
- Retrofit + Gson
- Room Database
- Firebase Authentication
- Coil

## Chức năng chính
- Hiển thị danh sách phim
- Tìm kiếm phim theo tên
- Lọc phim theo thể loại và năm phát hành
- Xem chi tiết phim
- Đăng ký, đăng nhập tài khoản
- Thêm/xóa phim yêu thích
- Đánh dấu phim đã xem/chưa xem
- Thống kê thể loại phim bằng biểu đồ ngang
- Chuyển đổi giao diện sáng/tối

## Cách chạy dự án
1. Mở project bằng Android Studio.
2. Đồng bộ Gradle.
3. Kết nối thiết bị thật hoặc mở Emulator.
4. Nhấn Run để chạy ứng dụng.
